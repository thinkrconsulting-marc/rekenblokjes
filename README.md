# Rekenblokjes

Rekenspel voor optellen en aftrekken met kwadraatbeelden (dominoblokjes).

Live: https://rekenblokjes.vercel.app

Elke push naar `main` wordt automatisch online gezet via Vercel.

Wijzigingen in het gedeelde Claude-artifact worden elk uur automatisch naar deze repo gezet (scripts/sync_artifact.py). Pas de site dus aan in het artifact, niet rechtstreeks hier.
